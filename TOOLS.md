# Sotto tool inventory

Updated November 18, 2026. All registered native tools support macOS 14+. Liquid Glass uses availability-gated newer APIs. **Verified** means the stated real operation passed here, not every permutation or spoken end-to-end scenario. **Implemented** means executable code exists but physical permission/service acceptance is incomplete. See [engineering record](docs/TOOLS-IMPLEMENTATION.md) for architecture, security and phase limits.

Tools expose namespaced IDs, display names, schemas, risk, capabilities/permissions, timeout, cancellation semantics, verification/undo notes and structured results. Existing IDs remain compatibility entry points.

Undo is not automatic. File move/rename results retain original/destination paths for an approved reverse move. Application opening, web opening, clipboard replacement, EventKit mutations and external Shortcut effects have no guaranteed rollback. Reversible risk indicates bounded ordinary operations, not universal undo.
